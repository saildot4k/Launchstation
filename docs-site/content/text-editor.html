Text Editor

A dashboard-native editor for configuration, scripts, argument lists and other text files.

Typical files

CNF, CFG, TXT, INI, CHT, PBT, JS, LUA, XML, TOML, YAML, YML and ARG files can be opened from File Browser.

Navigation

D-pad MoveL1/R1 Line start/endL2/R2 PageSquare SelectSTART Menu

The full current path is shown beneath the document title and scrolls when necessary. With the keyboard hidden, 18 lines of text fit above the footer; with it shown, 10 lines remain visible. Footer hints are intentionally compact enough for the PS2 safe width.

Editor menu

Save, Save As, New, Open, Switch Document, Start/Stop Selection, Select All, Copy, Cut, Paste, Line Endings, Go to Start, Go to End, Launch with Arguments, Close and Exit are available from START.

Document text follows the selected GUI font and Bold setting while keeping fixed-width columns. Special byte glyphs and the System font retain the active bitmap font.

On-screen and USB keyboards

Confirm opens the virtual keyboard. SELECT hides/shows it. The wide Space key inserts a space. On QWERTY, Tab sits left of Q and Return after the apostrophe; backslash sits beside the closing bracket on the row above. Return starts a new line. Delete uses the controller button, with no duplicate on-screen key. Symbols sits beside Space, keeping all controls within the five keyboard rows. Choose Symbols repeatedly to cycle through four-row, eleven-column pages of punctuation and extended characters, then return to your configured keyboard layout. The button shows the current symbols page. The whole keyboard is centered, including its side keys. Switching pages keeps the grid, Tab, Return and Space in the same positions. File and folder naming dialogs, including Save As, share the character layout and Space key, with Symbols, Tab and Return omitted. The slash/question-mark and backslash/pipe key positions are hidden in both Caps states. Their characters (/, ?, \ and |) are also rejected from USB keyboard input when entering names. START accepts a name; the controller delete shortcut remains available. Square toggles Caps, and Cancel deletes the previous character. USB keyboard input is supported when enabled and its driver is available.

Launch with arguments

Write one argument per line and choose Launch with these arguments…. The editor validates the buffer and hands argv to the same loader used elsewhere.
