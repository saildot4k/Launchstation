Text Editor

A dashboard-native editor for configuration, scripts, argument lists and other text files.

Typical files

CNF, CFG, TXT, INI, CHT, PBT, JS, LUA, XML, TOML, YAML, YML and ARG files can be opened from File Browser.

Navigation

D-pad MoveL1/R1 Line start/endL2/R2 PageSquare SelectTriangle Options

The full current path is shown beneath the document title and scrolls when necessary. With the keyboard hidden, 18 lines of text fit above the footer; with it shown, 10 lines remain visible. Footer hints are intentionally compact enough for the PS2 safe width.

Editor menu

Save, Save As, New, Open, Switch Document, Start/Stop Selection, Select All, Copy, Cut, Paste, Line Endings, Go to Start, Go to End, Use as launch arguments, Close and Exit are available from Triangle > Options, including while the virtual keyboard is shown.

Document text follows the selected GUI font and Bold setting while keeping fixed-width columns. Special byte glyphs and the System font retain the active bitmap font.

On-screen and USB keyboards

Confirm opens the virtual keyboard. SELECT hides/shows it. The wide Space key inserts a space and, on QWERTY, spans from the left edge of C to the right edge of period. In both the editor and naming keyboards, reversing the move into Space restores the previously selected key, even after inserting several spaces. While the keyboard is open, use the D-pad to select keys and tilt the right stick to move the text cursor in all four directions. L1/R1 also moves the cursor left/right, and L2/R2 moves it up/down. Tab and Return use the familiar keyboard arrow symbols, drawn independently of the selected font. They sit in a right-side column on rows 1 and 2, with Symbols on row 5. The side buttons are right-aligned, with spacing that fits beside the centered character grid. On QWERTY, backslash/pipe sits immediately after apostrophe/double quote. Return starts a new line. Delete uses the controller button, with no duplicate on-screen key. Choose Symbols repeatedly to cycle through four-row pages of punctuation and extended characters with the same column count as the chosen letter layout, then return to your configured keyboard layout. Its label stays Symbols on every page. The main character grid is centered independently of the side buttons. Switching pages keeps the grid width, Tab, Return and Space in the same positions. The editor keyboard sits lower to show 11 editable text rows above it, with a gap before the footer hints. The shared layout scales with the selected video mode. File and folder naming dialogs, including Save As, keep the same key arrangement and Space key, with Symbols, Tab and Return hidden. Naming keyboards center their visible keys; hidden actions do not reserve space. The question-mark key stays visible and types ? with Caps either off or on. Slash, backslash and pipe (/, \ and |) are hidden and also rejected from USB keyboard input when entering names. In naming dialogs, tilt the right stick left/right to move the text cursor while the D-pad selects keys. Naming popups show the title, destination folder path, typing area and keyboard in that order. Long folder paths scroll within their own line. The button helpers form one centered row. START accepts a name; the controller delete shortcut remains available. Square toggles Caps, and Cancel deletes the previous character. In both keyboards, holding Type or Delete repeats with the same initial delay and acceleration as list scrolling. USB keyboard input is supported when enabled and its driver is available.

Launch with arguments

Write one argument per line and choose Use as launch arguments. The editor validates the buffer and hands argv to the same loader used elsewhere.
