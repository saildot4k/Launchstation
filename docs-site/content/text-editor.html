Text Editor

A dashboard-native editor for configuration, scripts, argument lists and other text files.

Typical files

CNF, CFG, TXT, INI, CHT, PBT, JS, LUA, XML, TOML, YAML, YML and ARG files can be opened from File Browser.

Navigation

D-pad MoveL1/R1 Line start/endL2/R2 PageSquare SelectSTART Menu

The full current path is shown beneath the document title and scrolls when necessary. With the keyboard hidden, 18 lines of text fit above the footer; with it shown, 10 lines remain visible. Footer hints are intentionally compact enough for the PS2 safe width.

Editor menu

Save, Save As, New, Open, Switch Document, Start/Stop Selection, Select All, Copy, Cut, Paste, Line Endings, Go to Start, Go to End, Launch with Arguments, Close and Exit are available from START.

On-screen and USB keyboards

Confirm opens the virtual keyboard. SELECT hides/shows it. The wide Space key inserts a space. On QWERTY, Tab sits left of Q, Del after =, and Return after the apostrophe; backslash sits beside the closing bracket on the row above. Del deletes the previous character and Return starts a new line. Symbols sits beside Space, keeping all controls within the five keyboard rows. Choose Symbols repeatedly to cycle through four-row pages of punctuation and extended characters, then return to your configured keyboard layout. The button shows the current symbols page. File and folder naming dialogs, including Save As, share the character layout and Space key, with Symbols, Tab, Return and on-screen Del omitted. Forward slash and backslash are unavailable in names, including USB keyboard input. START accepts a name; the controller delete shortcut remains available. Square toggles Caps, and Cancel deletes the previous character. USB keyboard input is supported when enabled and its driver is available.

Launch with arguments

Write one argument per line and choose Launch with these arguments…. The editor validates the buffer and hands argv to the same loader used elsewhere.
