MMCE

Browse MMCE SD storage, manage files and launch supported applications and games.

Browsing

MMCE devices are represented through the device layer and can be opened on demand. The code does not reduce all MMCE use to one hard-coded slot; active device/card state is tracked explicitly.

Neutrino

Neutrino has a dedicated mmce backend. Launchstation can also discover a complete /neutrino/ install on the game device or on either memory-card slot.

Neutrino Game ID VMC selection

Launchstation loads MMCE on demand when launching supported Neutrino games and requests the Game ID VMC on responding adapters. MX4SIO exclusions and the emulated memory-card slot holding Neutrino follow R3Z 4.80. See Neutrino Game ID handling.
