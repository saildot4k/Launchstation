HDD Manager & APA Header Injection

Classic APA management is retained, with header injection tools for rebuilding or provisioning HDD-OSD style partition metadata.

Partition operations

The HDD Manager can inspect APA partitions and exposes creation/removal/rename/expand/format and related maintenance operations where supported. These actions are destructive; confirm the target disk and partition before writing.

Drive format

HDD Manager reports APA, exFAT, or FAT32 on the internal HDD. The scan checks for FAT/exFAT volumes even when APA is present, so APA-Jail and other hybrid drives can show APA Jail (APA + exFAT) or APA Jail (APA + FAT32) while retaining the APA partition list. Detection reads filesystem headers without mounting or writing to the drive and supports MBR, GPT, and extended partitions. A drive containing both exFAT and FAT32 volumes shows both formats. Unrecognized formats and failed reads are distinguished from confirmed filesystem types. Use File Browser to access exFAT or FAT32 files; HDD Manager's partition operations manage APA.

Browse partitions

The partition list displays original APA identifiers, as in classic wLaunchELF, without querying HDL game titles on cursor movement. D-pad Up/Down selects a partition; Left/Right jumps one page, stopping at the first or last partition before wrapping on the next press. Triangle opens Actions, including HDD status. Long selected partition names scroll in the list and details panel. PFS usage loads in the background, retaining recent mounts and cached figures for quick navigation.

Inject Header

For a selected PFS partition, the operations menu can inject header resources from device:/__Headers/<matching partition name>/. Supported source families include USB, MMCE and UDPFS.

Injection modes

ModeBehavior
This partition onlyInject only the selected partition from its matching header folder.
Matching partitionsScan __Headers and inject folders whose partitions already exist.
Matching and create missingInject existing matches, then prompt before creating each missing valid partition.

Safety

Header injection changes boot-visible partition metadata and can optionally create partitions. Keep known-good header folders and a backup of anything important before bulk operations.
