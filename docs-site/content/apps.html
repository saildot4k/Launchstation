Applications Library

Applications is the full library nested under Home, not an extra top-level tab. Use Home > Applications to browse configured folders, favorites, pinned apps and recents.

Home integration

The Continue carousel surfaces pinned, recent and favorite applications; Last folder is available after a valid path has been visited. SELECT cycles Grid, List and Carousel in the Applications library. Filters include All, All including hidden, Favorites and device categories. Choosing Applications as the Start screen opens All; ordinary visits keep the saved filter. During a scan, the viewer shows Looking for applications. If cached applications are on devices that are not ready, it says so instead of showing an empty Favorites message.

What is scanned

Only configured Application folders are scanned. Defaults:

mc:/APPS/
mc:/BOOT/
mass:/APPS/
mass:/BOOT/

Each configured root includes one subfolder level. This avoids silently crawling every attached filesystem.

Manage scan roots

Open Settings → Home & applications → Application library → Application folders.... Each current root is labeled “this folder + one subfolder.” Add Folder chooses an exact root; Restore Defaults restores the standard memory-card and mass roots.

Presentation

The dashboard can show application metadata and artwork when present. Long titles use bounded marquee behavior. Unfocused app rendering has stable alpha/scissor state so memory-card-style icons do not become half rendered.

Artwork & covers

Every application gets a default tile: a generated icon tinted per app. Its style is set in Settings > Customize theme > Icons > Default app icon. To show your own cover instead, add a PNG in one of the places below. Settings > Home & applications > Application artwork must be On.

Image format

  • PNG only (transparency is supported).
  • Any size up to 1.5 MB per file. Images are scaled down to fit 128×128 and never enlarged, so square art of 128×128 or more looks best. Interlaced PNGs are limited to 256×256.

Where Launchstation looks

For an app at mass:/APPS/OPL/OPNPS2LD.ELF, the first file found wins:

  1. A cover = line in the app's metadata sidecar (see below).
  2. Beside the ELF: OPNPS2LD.ELF_COV.png, OPNPS2LD_COV.png or OPNPS2LD.png.
  3. In the app's own folder (not a scan root such as mass:/APPS/ itself): cover.png or icon.png.
  4. Beside the ELF: OPNPS2LD_ICO.png (OPL disc-icon naming).
  5. An ART folder at the root of the same device, using OPL naming: mass:/ART/OPNPS2LD.ELF_COV.png or mass:/ART/OPNPS2LD_COV.png (the +OPL partition on an internal HDD).
  6. An ART folder in Launchstation's settings folder (beside DASHBOARD.CNF): OPNPS2LD.ELF_COV.png, OPNPS2LD_COV.png or OPNPS2LD.png. Use this for apps on devices that are not started yet.

Covers prepared for OPL's ART folder work as-is.

Choosing a cover in metadata

Use Application options > Edit metadata from Home or Applications to open title.cfg beside the ELF. If it is missing, Launchstation offers to create it with the app title and ELF filename. It uses plain key = value text:

title = Open PS2 Loader
boot = OPNPS2LD.ELF
cover = covers/opl.png

A relative cover path is resolved from the ELF's folder; a full path such as mc0:/ART/opl.png also works. art and icon are accepted as synonyms. Existing ELF-specific sidecars such as OPNPS2LD.cfg are still read by the library.

After adding art

Choose Refresh library (Applications options) or Settings > Home & applications > Application library > Refresh library now. Covers already found are kept, and apps that had none are checked again. Saving from Edit metadata re-reads that one app immediately.

Favorites and app metadata

Application options can add/remove Favorites, pin a shortcut, edit metadata and show the app in File Browser. Favorite changes show a toast. In the Applications Options menu, Hide from view sits above Refresh library. Hidden applications are omitted from Home and normal library filters; their ELFs, favorites and pins are kept. The choice survives refreshes and restarts. To restore one, choose Show applications > All including hidden (directly below All), select it, then choose Show in view. Hidden paths are saved in DASHAPPS.CNF, independently of the library cache.

Launching

ELFs use the shared loader path. Optional argument sidecars and the Text Editor's “Launch with these arguments” action can provide custom argv.
