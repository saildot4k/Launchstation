Privacy Policy

Launchstation is free, open-source PlayStation 2 homebrew. It has no accounts, no analytics and no servers of its own. This page explains the little data it handles and where it goes.

Summary

  • Launchstation does not collect, sell or share personal data.
  • There is no telemetry, advertising or tracking.
  • Everything Launchstation stores stays on your own PS2 storage (memory card, USB, HDD and similar).
  • Network features run only when you use them, and talk directly to the services listed below.

Other network features

  • Check for updates contacts the GitHub API and downloads release files from GitHub when you ask it to. GitHub's own privacy statement applies to those requests.
  • Clock synchronization, when used, asks 0.pool.ntp.org for the current time. No personal data is sent.
  • Network file sharing (host/UDPFS and similar) connects only to computers you configure on your own network.

Like any internet request, these services can see your IP address. Launchstation adds no identifiers of its own.

Children

Launchstation does not knowingly collect data from anyone, including children.

Changes and contact

Changes to this policy are published on this page and in the project's GitHub repository. Questions can be raised as a GitHub issue.
